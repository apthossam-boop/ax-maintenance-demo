# بوابة صيانة AX 2012

## التشغيل (وضع SQL — بيانات حقيقية)
1. شغّل `start-api.bat`
2. افتح http://localhost:8080
3. عميل: رقم تليفون من AX مثل `01028525303`
4. مستخدمو الشركة: http://localhost:8080/company.html (`staff` / `staff123`)
